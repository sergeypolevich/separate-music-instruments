- **Model weights:** Demucs 4.1 downloads safetensors from Hugging Face (`adefossez/…`, unpinned) but builds the model class named in the file's metadata, so a swapped file could call any Python function; beat_this downloaded `final0` from cloud.cp.jku.at unchecked and unpickled it in full (`weights_only=False`); BS-RoFormer SW is loaded with `weights_only` (torch 2.14 default) but unchecked.
