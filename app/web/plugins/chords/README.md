# Chords

Finds the song's chords and shows their names in a row over the tracks, so you can play along.

## How to use

1. Press **Find chords** in the plugins' row under the player. It takes some seconds; the button shows the progress.
2. The chord names appear over the tracks, each at the start of its chord.
3. A chord name is wrong? Click it, type the right one and press Enter. Esc cancels, an empty name removes the chord.
4. The **Chords** button hides and shows the names.

## Good to know

- The chords are found on this computer, from all stems but the vocals and drums.
- Major and minor chords are found (24 of them), on the beats if the beats are known, otherwise every half second.
- Your corrections are kept with the project.
- Settings → Plugins → Chords: the text size and bold.

## Permissions

- **Runs an analysis on this computer:** finding the chords.
