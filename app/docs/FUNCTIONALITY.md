# Audio Stems — функциональность с точки зрения пользователя

Документ фиксирует, что приложение умеет сейчас. При рефакторинге поведение должно остаться таким же, кроме пунктов, помеченных **«убирается»**.

## 1. Запуск

- Скачивание (с версии 19): в README две ссылки на архивы последнего релиза — для Windows и для macOS, в каждом один файл запуска своей системы. Файлы запуска называются `Start Windows.bat` и `Start MacOS.command` (до версии 19 — `Start.bat` и `Start.command`; у тех, кто обновился встроенным обновлением, прежние файлы остаются и работают). При первой установке на Windows на рабочем столе появляется ярлык «Audio Stems» с иконкой приложения (один раз: удалённый ярлык не возвращается); у `Start MacOS.command` в архиве для macOS своя иконка.
- Двойной клик по `Start Windows.bat` в корне папки проекта. При первом запуске ставится Python 3.12 (если его нет), в папке `app` создаётся `.venv` и устанавливаются зависимости из `app/requirements-windows.lock` (на macOS — `requirements-macos.lock`): точные версии всех пакетов, каждый файл сверяется по SHA-256; включая ffmpeg (пакет `imageio-ffmpeg`) — ставить ffmpeg в систему не нужно.
- Повторные запуски не проверяют зависимости заново: пока lock-файл совпадает с установленным, приложение стартует сразу (проверка ~0,02 с). Если зависимость пропала или lock-файл изменился (например, после обновления из GitHub), `Start Windows.bat` сам запускает доустановку.
- На Mac — двойной клик по `Start MacOS.command` (в первый раз: правый клик → «Открыть»). Если Python 3.12 нет, он ставится только для этого пользователя, без пароля администратора; дальше всё как в Windows. Поддерживаются Chrome и Safari 16.4+.
- Запускаются два процесса: локальный API и отдельный фоновый worker. Как только API готов, в браузере открывается `http://127.0.0.1:8000`.
- Окно с логами сервисов остаётся открытым; его закрытие останавливает оба процесса.
- Ручной запуск для разработки: `py run.py --app`. Отдельно API и worker: `py run.py --api` и `py run.py --worker`.
- Удалён старый консольный режим `download_tracks.py`; `py run.py` без аргументов теперь запускает приложение, как `--app`.

## 2. Новая задача (свой файл или поиск)

- Строка «Открыть аудиофайл или найти песню…» в шапке открывает полноэкранную панель «Что будем разделять?».
- **Свой файл** (с версии 15) — первым пунктом: кнопка «Открыть аудиофайл» (можно выбрать несколько файлов) или перетаскивание файлов в любое место окна (появляется рамка «Отпустите, чтобы разделить»). Форматы: MP3, WAV, FLAC, M4A, MP4, AAC, OGG, Opus, WebM, AIFF, WMA; до 500 МБ на файл (`AUDIO_STEMS_UPLOAD_LIMIT_MB`). Файл, который не похож на аудио, отклоняется с сообщением. Проект называется по имени файла без расширения; копия файла сохраняется в `Music/`, оригинал не трогается. Тот же файл, открытый повторно, не копируется ещё раз.
- **Поиск песни** — ниже, «или найдите песню» (поле «Название песни или ссылка»). В поле можно ввести одну или несколько строк, до 2048 символов: Enter запускает поиск, Shift+Enter добавляет строку (с версии 16). Подсказка в панели одна — «Несколько песен — каждая с новой строки» (с версии 17 панель не повторяет про YouTube и Enter). Каждая строка становится отдельной задачей:
  - название песни или исполнителя — берётся **первый** результат поиска YouTube;
  - ссылка `youtube.com` или `youtu.be` — обрабатывается **именно это** видео, без поиска по названию. Другие сайты отклоняются с сообщением «Ссылка не подходит: поддерживаются ссылки YouTube (youtube.com, youtu.be)».
- Модель разделения выбирается в «Настройках» (см. раздел 6).
- Устройство не выбирается: используется лучшее доступное — CUDA, затем Apple MPS, затем CPU (можно задать явно через `AUDIO_STEMS_MODEL_DEVICE` в `.env`).
- Кнопка «Начать разделение». Панель закрывается кнопкой ×, клавишей Esc или кликом мимо панели.
- В одном пакете не больше 25 строк (настраивается).

## 3. Обработка

- Сначала скачивается аудио для **всех** задач пакета. Разделение на дорожки начинается только после этого.
- Аудио: предпочитается поток `audio/webm` с наибольшим битрейтом (на YouTube без Premium это opus ~130–160 кбит/с), если его нет — другой поток только со звуком. Потоки со сжатой динамикой (DRC) не берутся. Файл сохраняется как есть, без перекодирования.
- Скачивание повторяется до 3 раз с паузами 3 и 6 секунд (настраивается).
- Ошибка одной задачи не останавливает остальные задачи пакета.
- Готовое аудио, которое уже есть на диске и проходит проверку, используется повторно; полный набор дорожек той же модели тоже не пересчитывается. Неполный набор пересчитывается. Та же песня, разделённая другой моделью, получает свой набор.
- Разделение без потерь качества: внутри всё считается в 32-битном float, громкие дорожки не обрезаются и не ужимаются по отдельности; при сохранении все дорожки проекта получают одну общую поправку громкости, так что баланс между ними не меняется.
- Ход работы виден по заливке вкладки и по полосе прогресса внутри открытого проекта: 0% сразу после «Начать разделение», загрузка аудио — до 10%, разделение — до 97%, 100% — дорожки готовы; по окончании проект сам превращается в микшер. С версии 17 вкладка при поиске сразу называется найденным видео, а когда песня скачана, над полосой прогресса её можно послушать одной дорожкой «Original» (без вейвформы, метронома и скорости) — проверить, что скачалось то, что нужно. Обновляется раз в секунду, в том числе после перезагрузки страницы.
- Очередь (с версии 17): пока есть работа, в шапке слева от «?» крутится колесо; у идущей задачи оно заполняется её прогрессом. По нажатию — список: текущая задача, затем песни в очереди, затем «Улучшить качество» в очереди, у каждой — этап и сколько осталось, и крестик «Отменить»; строка идущей задачи заливается фоном по мере работы (без заголовка и без процентов словами). Идущую задачу перед отменой нужно подтвердить, ожидающая отменяется сразу. Все подтверждения — в окне приложения, а не в окне браузера (с версии 18).
- Отмена (с версии 17): в открытом проекте крестик справа от полосы прогресса (с версии 18.1; до неё — кнопка «Отменить» под полосой), у идущего улучшения — крестик. Полоса с подписью этапа стоит под дорожками (во время разделения — под дорожкой «Original»), а пока песня загружается и дорожек ещё нет — сразу под шапкой (с версии 18.1). Отменённая до конца загрузки песня удаляется вместе с проектом. Отменённая во время разделения остаётся проектом с дорожкой «Original» и кнопкой «Разделить» (она же появляется, если разделение не удалось): песня снова встаёт в очередь и разделяется из уже скачанного файла, без нового поиска. Отменённое улучшение оставляет прежние дорожки.
- Оценка времени: пока проект в очереди или загружается — «разделение займёт ~N мин» (сколько это обычно длится на этом компьютере: медиана последних пяти разделений той же модели; пока своей истории нет — по замерам на тестовом ноутбуке); во время разделения — «осталось ~N мин».
- Если на диске не хватает места, задача останавливается с сообщением «Недостаточно места на диске: нужно ~X МБ, свободно Y МБ» — его видно в проекте.
- Если приложение перезапустили во время обработки, незавершённая работа подхватывается снова.

## 4. Проекты

- Каждая задача — проект. Проекты показаны горизонтальными вкладками под шапкой во всю ширину; текст 14 px. Точка есть только у проектов в работе (серая) и с ошибкой (красная); у готовых проектов точки нет — это обычное состояние. Полоса вкладок прокручивается колёсиком мыши или перетаскиванием, без полосы прокрутки; у краёв, за которыми есть ещё вкладки, — затухание. Справа от вкладок кнопка «Все проекты» (с версии 18): вертикальный список всех проектов, у работающего — заливка прогресса; клик открывает проект, крестик удаляет его после подтверждения в окне приложения (с размером, как у корзины); проект, который ещё загружается или разделяется, сначала отменяется («Отменить и удалить»). Закрывается Esc или кликом мимо.
- Клик по вкладке открывает проект без рамки и боковых полей: слева, над колонкой дорожек, общая громкость (с версии 18); над вейвформами — крупные кнопки ▶, 4▶ (отсчёт) и ⏮, за ними название и прижатый к правому краю таймер (на узком экране названия нет — его показывает вкладка, с версии 18.3; до неё название стояло под кнопками) (того же размера, тонким шрифтом); ниже микшер. Название занимает не больше двух строк: если не помещается, конец второй строки плавно затухает, полное название — во всплывающей подсказке (с версии 17). Подсказка «Найдите песню…» видна только когда проектов нет совсем.
- Если проект завершился ошибкой, внутри показывается понятный текст ошибки.
- Рядом с корзиной написано, сколько проект занимает на диске (исходное аудио и дорожки).
- Удаление: красная кнопка с корзиной, подтверждение в окне приложения («Освободится X МБ»). Удаляются проект, исходное аудио, все дорожки, вейвформы, опустевшая папка дорожек и временные файлы неудачного разделения этой песни. Файлы, которые использует другой проект (та же песня, разделённая ещё раз), остаются ему — окно об этом пишет. Если файл в этот момент занят (Windows), удаление повторяется, а незавершённая очистка доделывается при следующем запуске.
- Если файлы готового проекта удалили с диска вручную, проект пишет, каких файлов нет, и предлагает «Разделить заново»: сломанный проект удаляется, та же песня ставится в очередь с той же моделью.
- «Улучшить качество · ~N мин» (со значком-звёздочкой; у готового улучшения — галочка, с версии 18) внизу проекта, между метрономом и скоростью: песня разделяется заново лучшей моделью (BS-RoFormer SW). Время — медиана этой модели на этом компьютере × длина песни. Пока идёт улучшение (после задач в очереди), на кнопке заливка, процент и «осталось ~N мин», а проект играет как обычно. Когда новые дорожки готовы, плеер сам переходит на них с той же позиции, скорости и состоянием метронома (если играло — играет дальше), а старые дорожки удаляются с диска (кроме тех, что нужны другому проекту; файл, который Windows ещё держит, остаётся среди «файлов без проекта»). Проект, уже разделённый лучшей моделью, показывает неактивную кнопку «Улучшенное качество разделения». Пока идёт улучшение, проект нельзя удалить.

## 5. Воспроизведение (микшер)

- Работает, когда доступны все дорожки проекта (4 или 6, FLAC или WAV); иначе выводится пояснение.
- Общая громкость — значок динамика над ползунком, как у дорожек (с версии 18.3; раньше слева от него), в шапке проекта над колонкой дорожек (с версии 18; с версии 16 — строка под дорожками, до версии 17 подписанная «Общая»): громкость всего микса 0–100 %, метроном она не трогает; запоминается для каждого проекта в браузере.
- У каждой дорожки перед названием значок (с версии 17; с версии 18 — иконки Delapouite с game-icons.net, CC BY 3.0): микрофон — Vocal, барабан — Drums, головка грифа баса — Bass, головка грифа гитары — Guitar, клавиши — Piano, труба — Other. На узком экране (до 600 px) вместо названия только первая буква (она же горячая клавиша дорожки), и колонка с кнопками уже.
- Все дорожки играют синхронно и складываются ровно в сумму дорожек: плеер работает на частоте самих дорожек (44,1 кГц), а к частоте звуковой карты весь микс приводится один раз на выходе. Раньше Chrome пересчитывал каждую дорожку в 48 кГц отдельно, и на ярких звуках (например, гитара во вступлении рок-песни) появлялся треск. Кнопки: ▶ — старт, ❚❚ — пауза, ⏮ — остановить всё и вернуться в начало.
- Тишина в начале трека пропускается: ноль позиции — первый звук (громче −50 dBFS в любой дорожке, минус 20 мс). Файлы не обрезаются.
- 4▶ — отсчёт: нажатие — «клик 0» (тишина в одну долю), затем 4 клика в темпе песни, и музыка идёт по её сетке (при затакте начинается во время отсчёта). Без метронома дальше тишина метронома, с метрономом он продолжает. Пробел, ▶ или 4▶ во время отсчёта отменяют его.
- Метроном — кнопка-значок под дорожками (с версии 17 без слова «Метроном»: оно во всплывающей подсказке; включённая кнопка залита акцентным цветом) и громкость 0–100% (50% ≈ громкость проекта, 100% вдвое громче; громкость проекта не меняется). Щелчки идут по долям, найденным в самой песне: модель beat_this оценивает, где доли, а с версии 16 доли выбираются одной цепочкой через всю песню — без двойных щелчков и перескоков фазы. Песня с ровным темпом (электронная, студийная под клик) получает идеально ровную сетку, темп, близкий к целому, округляется (150,016 → 150); живой темп метроном сглаженно повторяет. Проекты, проанализированные раньше, при первом включении метронома анализируются заново (~30 с). Рядом с кнопкой — темп песни: у ровной одно число, у живой оно меняется по ходу (значения посчитаны при анализе раз в 4 доли), с учётом скорости воспроизведения, до десятых без «.0» (150 BPM, 151.1 BPM). Доли определяются при первом нажатии (~30–40 с на песню, прогресс заливкой кнопки и в подсказке) и запоминаются. Если ровного ритма нет (темп ниже 40 или выше 240 BPM, меньше 8 долей — например, речь), рядом с кнопкой написано «Ритм не найден», и метроном, его громкость и 4▶ недоступны.
- Скорость — 25–150% с шагом 5% без изменения высоты нот, фейдер под дорожками между значками черепахи (медленнее) и зайца (быстрее), двойной клик — 100%. Выбранное значение — подсказкой над ползунком при наведении и перетаскивании (с версии 17 слово «Скорость» и проценты справа не пишутся). Над шкалой подписи 25%, 100%, 150%, на шкале штрих у каждого возможного значения, отметка 100% длиннее. На 100% дорожки играют как обычно; при первой другой скорости они один раз загружаются в память (несколько секунд, около 0,5 ГБ на 4-минутную песню, освобождается при смене проекта) — блок скорости в это время заливается полупрозрачным прогрессом, а над ползунком видно «подготовка N%» — и растягиваются алгоритмом Signalsmith Stretch; дальше скорость меняется мгновенно. Метроном и отсчёт попадают в доли на любой скорости (расхождение в пределах ~10 мс). Смена скорости работает на самом компьютере; с телефона или другого компьютера по адресу в сети браузер не даёт нужную ей технологию (AudioWorklet, только для https), там ползунок неактивен.
- Зацикленный повтор (с версии 19): протяните мышью (или пальцем) по вейвформам — между точками появится подсвеченная полоса, и ▶ играет только её по кругу, без паузы на стыке. Края прилипают к ближайшим долям: петля начинается и заканчивается кликом метронома, не короче одной доли. Если доли ещё не определялись, анализ запускается сам (прогресс на кнопке метронома), и петля сдвигается по его окончании; если ритм не найден — остаётся как выделили. Для петли дорожки загружаются в память (несколько секунд в первый раз, как при смене скорости); метроном щёлкает через стык, скорость меняется как обычно. Короткий клик по-прежнему перематывает (раньше протягивание прокручивало песню). Петля сбрасывается двойным кликом по ней, кликом вне её (с перемоткой туда), стрелками за её пределы, Esc, Home или ⏮.
- iPhone и iPad (с версии 18.2): Safari после паузы запускал дорожки по очереди, и они расходились. Теперь там дорожки при открытии проекта сразу загружаются в память (несколько секунд, «Подготовка дорожек…» под плеером; ▶ ждёт окончания) и играют по одним часам — синхронно после любых пауз и перемоток. На других устройствах так же можно включить, добавив к адресу `?engine=decoded` (под плеером видно время подготовки).
- Отдельной шкалы времени нет: позицию показывает одна тонкая вертикальная линия через все вейвформы.
- Клик или перетаскивание в любом месте колонки вейвформ (включая промежутки между дорожками) перематывает все дорожки в это место.
- У каждой дорожки своя вейвформа — сплошная форма по 1024 пикам громкости, плавно подстраивается под любую ширину окна.
- Громкость каждой дорожки от 0 до 150% — ползунок без рамки и без подписи процентов, с тонкой отметкой на 100%; около 100% ползунок мягко фиксируется на обычном уровне. Громкость меняется только мышью.
- Кнопки S и M стоят в строке с названием дорожки, у правого края. Нажатая S — жёлтая, нажатая M — красная, с белыми буквами. M — выключить дорожку. S — оставить звучать только выбранные; можно включить несколько S одновременно. Вейвформы дорожек, заглушённых через S/M, становятся прозрачнее на 80%.
- Клик мышью по кнопке, вкладке или области позиции с последующим нажатием клавиши не рисует рамку фокуса.
- Горячие клавиши (когда проект открыт и курсор не в поле ввода): Пробел или Enter — воспроизведение/пауза; ←/→ — на 5 с назад/вперёд; Home — в начало (End с версии 18 не используется); Backspace — как кнопка ⏮: в начало и пауза (с версии 16); ↓/↑ — выбор дорожки: следующая / предыдущая (отмечена полоской слева); Tab / Shift+Tab — следующая / предыдущая дорожка по кругу; V, D, B, G, P, O — Vocal, Drums, Bass, Guitar, Piano, Other; S и M — кнопки выбранной дорожки; + и − (на основной клавиатуре клавиши = и -, а также на цифровом блоке) — громкость выбранной дорожки шагами по 10 % в пределах 0–150 %, у 100 % она «прилипает», как при перетаскивании (с версии 16); 1–9 — открыть вкладку 1–9, Q / W — предыдущая / следующая вкладка по кругу (с версии 18; клавиши по положению, работают в любой раскладке и пока у проекта ещё нет плеера); Ctrl+F — поиск.
- Tab не переводит фокус по кнопкам и не рисует рамку фокуса (кроме окон поиска, настроек и удаления, где Tab работает как обычно).

## 6. Настройки

- Открываются шестерёнкой в шапке во всплывающем окне поверх проекта; проект под ним продолжает играть, горячие клавиши плеера, пока окно открыто, не действуют. Закрываются кликом мимо окна, Esc или ×.
- Справка (с версии 17): значок «?» в шапке слева от настроек открывает окно «Горячие клавиши» — список: действие и сразу за ним его клавиши (несколько — через запятую), без линий между строками (с версии 18); закрывается ×, Esc или кликом мимо окна; пока оно открыто, горячие клавиши не действуют.
- «Оформление»: тема — кнопки с луной (ночная) и солнцем (дневная) — и ползунок акцентного цвета (по умолчанию голубой, оттенок 197; до версии 16 — зелёный, 84). Меняются сразу и запоминаются в этом браузере. Дневная тема (с версии 17) почти белая, без цветного свечения на фоне; кнопки, вкладки и поле поиска залиты светло-серым без рамок, рамка появляется при наведении.
- «Разделение»: модель для новых задач, запоминается в этом браузере. Всё считается локально и бесплатно. У каждой модели написано время разделения одной минуты песни: медиана последних пяти разделений этой модели на этом компьютере, а пока их нет — оценка по тестовому ноутбуку (4-ядерный i7 без NVIDIA) с пометкой «уточнится после первого разделения»:
  - **Demucs, быстрая** (`hdemucs_mmi`, shifts 2, 4 дорожки: вокал, барабаны, бас, прочее; гитара и клавишные — в «прочем») — около 1,2 мин на минуту песни; модель по умолчанию;
  - **BS-RoFormer SW** (6 дорожек, overlap 1) — около 7 мин на минуту песни; на слух заметно лучше всех проверенных моделей, ею же работает «Улучшить качество».
  - Прежняя быстрая модель `htdemucs_6s` в списке больше не предлагается; проекты, сделанные ею, открываются и разделяются заново как прежде.
- «Место на диске»: сколько занимают проекты, файлы без проекта, временные файлы разделения и веса моделей. «Очистить» удаляет файлы без проекта и временные файлы (после подтверждения; пока идёт разделение, кнопка неактивна). Проекты и служебный индекс хранилища не затрагиваются. «Удалить все проекты (X ГБ)» удаляет все проекты так же, как корзина, после одного подтверждения с размером; пока идёт разделение или улучшение, обе кнопки неактивны.
- «Настройки» → «Обновления» → «Проверить» (только по нажатию): установленная версия и описания более новых версий с GitHub. «Обновить до vNN» (номера вида 18 или 18.1, с версии 18.1) после подтверждения скачивает самую новую (пока в очереди нет задач); после перезапуска приложения она устанавливается до открытия: заменяются файлы программы, а песни, база, настройки (`app/.env`) и среда Python остаются; если изменился список библиотек, лаунчер сам их доустанавливает. Копия, скачанная через git, обновляется через git (только без своих правок). С версии 17; до неё кнопка обновляла только зависимости и фактически не работала.

## 7. Файлы на диске

- Корень: `~/Audio Stems/Music/`. До версии 15 папка называлась `YouTube Audio`; при первом запуске новой версии лаунчер переименовывает её сам (если в ней открыт файл — в другой раз, а пока работает со старой).
- Исходное аудио: `<название видео>.<расширение>` прямо в корне.
- Веса beat_this (метроном, ~80 МБ) скачиваются при первом нажатии метронома в кэш torch.
- Дорожки модели `htdemucs_6s` (быстрой до версии 13): `Stems/<название видео>/vocals.flac`, `drums.flac`, `bass.flac`, `guitar.flac`, `piano.flac`, `other.flac` — без подпапок для отдельных дорожек. Других моделей — рядом, в `Stems/<название видео> (<модель>)/`. FLAC 16 бит занимает около 19–22 МБ на минуту песни (WAV до версии 10 — около 61 МБ); проекты, сделанные раньше, остаются в WAV и играют как прежде.
- Веса моделей BS-RoFormer скачиваются при первом разделении в `~/Audio Stems/models/` (около 700 МБ), веса Demucs — в кэш torch.
- Недопустимые в Windows символы и зарезервированные имена устройств в названиях заменяются. Если два разных видео называются одинаково, к имени добавляется идентификатор видео, чтобы файлы не перезаписались.
- База проектов: `~/Audio Stems/audio_stems.db`. Логи: `~/Audio Stems/logs/` (JSON Lines с ротацией).

## 8. Скорость и отзывчивость (версия 4)

- Готовый проект открывается быстро: при самом первом открытии вейвформы шести дорожек считаются примерно за 0,5 с и сохраняются в базу; дальше, в том числе после перезапуска, — около 0,03 с (в версии 3 было около 110 с).
- Во время воспроизведения можно сразу переключиться на другой проект, удалить проект или запустить новую задачу: аудио загружается с соседнего локального адреса (`localhost` ↔ `127.0.0.1`) и не занимает соединения, нужные интерфейсу.
