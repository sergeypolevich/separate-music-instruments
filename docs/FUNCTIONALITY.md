# Audio Stems — функциональность с точки зрения пользователя

Документ фиксирует, что приложение умеет сейчас. При рефакторинге поведение должно остаться таким же, кроме пунктов, помеченных **«убирается»**.

## 1. Запуск

- Двойной клик по `Start Audio Stems.bat`. При первом запуске ставится Python 3.12 (если его нет), создаётся `.venv` и устанавливаются зависимости из `requirements.txt`.
- Запускаются два процесса: локальный API и отдельный фоновый worker. Как только API готов, в браузере открывается `http://127.0.0.1:8000`.
- Окно с логами сервисов остаётся открытым; его закрытие останавливает оба процесса.
- Ручной запуск для разработки: `py run.py --app`. Отдельно API и worker: `py run.py --api` и `py run.py --worker`.
- Удалён старый консольный режим `download_tracks.py`; `py run.py` без аргументов теперь запускает приложение, как `--app`.

## 2. Новая задача (поиск)

- Строка «Найти песню или вставить YouTube-ссылку…» в шапке открывает полноэкранную панель «Что будем разделять?».
- В поле можно ввести одну или несколько строк, до 2048 символов. Каждая строка становится отдельной задачей:
  - название песни или исполнителя — берётся **первый** результат поиска YouTube;
  - ссылка `youtube.com` или `youtu.be` — обрабатывается **именно это** видео, без поиска по названию. Другие сайты отклоняются.
- Выбор модели разделения: сейчас доступна одна, `htdemucs_6s`.
- Устройство не выбирается: используется лучшее доступное — CUDA, затем Apple MPS, затем CPU (можно задать явно через `AUDIO_STEMS_MODEL_DEVICE` в `.env`).
- Кнопка «Начать разделение». Панель закрывается кнопкой ×, клавишей Esc или кликом мимо панели.
- В одном пакете не больше 25 строк (настраивается).

## 3. Обработка

- Сначала скачивается аудио для **всех** задач пакета. Разделение на дорожки начинается только после этого.
- Аудио: предпочитается поток `audio/webm` с наибольшим битрейтом, если его нет — другой поток только со звуком.
- Скачивание повторяется до 3 раз с паузами 3 и 6 секунд (настраивается).
- Ошибка одной задачи не останавливает остальные задачи пакета.
- Готовое аудио, которое уже есть на диске и проходит проверку, используется повторно; полный набор из шести дорожек тоже не пересчитывается. Неполный набор пересчитывается.
- Разделение: Demucs `htdemucs_6s`, шесть дорожек — вокал, барабаны, бас, гитара, фортепиано, прочее.
- Ход работы виден по статусу проекта: поиск → загрузка аудио → аудио загружено → разделение → готово / ошибка.
- Если приложение перезапустили во время обработки, незавершённая работа подхватывается снова.

## 4. Проекты

- Каждая задача — проект. Проекты показаны горизонтальными вкладками под шапкой, цвет вкладки показывает статус: в работе, готово (зелёный), ошибка (красный).
- Клик по вкладке открывает проект: название, исходный запрос, модель.
- Если проект завершился ошибкой, внутри показывается понятный текст ошибки.
- Кнопка ↻ обновляет список проектов.
- «Файлы проекта»: исходное аудио и шесть дорожек с форматом и размером; ссылка «Открыть» открывает файл в новой вкладке. Отсутствующий на диске файл помечается «Файл не найден».
- Удаление: красная кнопка с корзиной, подтверждение в окне приложения. Удаляются проект, исходное аудио и все дорожки.

## 5. Воспроизведение (микшер)

- Работает, когда у проекта есть все шесть WAV-дорожек; иначе выводится пояснение.
- Шесть дорожек играют синхронно. Кнопки: ▶ — старт, Ⅱ — пауза, |◀ — остановить всё и вернуться в начало.
- Общая шкала времени с текущим временем; перетаскивание или клик перематывает все дорожки.
- У каждой дорожки своя вейвформа.
- Громкость каждой дорожки от 0 до 150%; около 100% ползунок мягко фиксируется на обычном уровне.
- M — выключить дорожку. S — оставить звучать только выбранные; можно включить несколько S одновременно.

## 6. Настройки и справка

- «Настройки» → «Обновления» → «Проверить». Проверка запускается только по нажатию: показываются релизы проекта на GitHub, выбранное обновление закреплённых зависимостей ставится только после подтверждения.
- «Справка» — инструкция на русском по всем шагам выше.

## 7. Файлы на диске

- Корень: `~/Audio Stems/YouTube Audio/`.
- Исходное аудио: `<название видео>.<расширение>` прямо в корне.
- Дорожки: `Stems/<название видео>/vocals.wav`, `drums.wav`, `bass.wav`, `guitar.wav`, `piano.wav`, `other.wav` — без подпапок для отдельных дорожек.
- Недопустимые в Windows символы и зарезервированные имена устройств в названиях заменяются. Если два разных видео называются одинаково, к имени добавляется идентификатор видео, чтобы файлы не перезаписались.
- База проектов: `~/Audio Stems/audio_stems.db`. Логи: `~/Audio Stems/logs/` (JSON Lines с ротацией).
